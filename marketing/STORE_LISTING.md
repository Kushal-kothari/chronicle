## ⚔️ Competitive context (read first)

Chronicle is a fork of **"Web Activity Time Tracker - Block Websites, Pomodoro & Web Analytics"** by *Media IntelliView* (`hhfnghjdeddcfegfekjeihfmbjenlomm`) — **50,000 users, 4.8★, 920 ratings.** That incumbent owns the exact keywords we want. We will **not** out-rank it on raw install count soon. The winnable strategy:

1. **Differentiate on positioning, not features.** They're "block + pomodoro + analytics." Chronicle is *"see where your attention goes and shape it"* — categories, goals, focus sessions, weekly insights, **100% private/local**. Lean hard into **privacy** and **insight**, which their listing barely mentions.
2. **Win the long-tail keywords** they don't optimize for: *screen time*, *digital wellbeing*, *focus timer*, *attention*, *private/local time tracker, no account*.
3. **Velocity + recency + ratings** are ranking signals you control: ship small updates often, and convert engaged users to reviews (see Growth Playbook).

## 🚀 Growth Playbook (off-repo levers — do these in the Dashboard / externally)

The repo can't push these buttons; you must. In rough priority:

1. **Re-save the listing** with the title/summary/description above for **all 6 locales**. Title change alone is the biggest single search lever.
2. **Ship updates frequently.** Recency is a ranking signal. Even small version bumps + a changelog line help. Aim for a release every 1–2 weeks while growing.
3. **Convert engaged users to reviews — ethically.** The in-app review prompt (shipped in this repo) asks only users who've used Chronicle ≥5 days and ≥4 active days. More 5★ reviews ≈ higher rank + higher conversion. Never incentivize or fake reviews (CWS will penalize).
4. **Drive external traffic to the listing** so install velocity rises: share the landing page (`docs/`), post in r/productivity, r/getdisciplined, r/chrome_extensions, Product Hunt, Hacker News "Show HN", and relevant Discords. Velocity matters more than absolute count for ranking.
5. **Win the privacy/open-source angle** in content: a short blog post "a screen-time tracker that never phones home," linking the listing, earns backlinks and ranks in Google (which feeds CWS too).
6. **Watch the funnel** in the Dashboard's analytics: impressions → listing views → installs → 7-day retention. Improve whichever stage is weakest. Today the weak stage is *impressions* (≈0.5 listing views/day) — steps 1, 4, 5 attack that directly.
7. **A/B the listing** if you have a second locale to experiment with: try a more benefit-led title vs. the keyword-led one and compare install rate.

### What's explicitly NOT possible from code
Editing the live listing, generating real installs/reviews, rendering the screenshot/promo images, and directly setting search rank. Those are Dashboard + marketing actions for you; everything feeding them is done in the repo.
